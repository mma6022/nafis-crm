# CSS تحویل چندپرونده

گزیدهٔ آماده از منبع طرح مصوب `screens/multi-case` نسخهٔ ۱.۱، فقط برای هم‌تراز کردن ساخت با طرح. جایگزین کل پوسته‌ی CRM نیست.

## فایل

`multicase.css` — کارت پرونده، انتخاب‌گر تماس/یادآور، بازبینی ویزارد، نشان `#id`، دکمه، تلفن LTR، برچسب «نمونه»، و حالت مسدود طرح تکراری (v1.1).

## بایدها

- روی سند بگذارید: `<html lang="fa" dir="rtl">`. بدون این، مرورگر ممکن است پنجرهٔ ترجمه نشان بدهد و چینش LTR شود.
- فونت اصلی: `Vazirmatn` (سپس Tahoma / Segoe UI). فایل `@import` فونت گوگل را دارد؛ در تولید بهتر است خودمیزبان شود.
- رنگ اصلی را `rgb(41, 54, 155)` بنویسید، نه هگز.
- نام طرح را از سرور بگیرید. جای‌نگهدار نمونه فقط: «لندتک / بانک منتخب — نمونه ۱» و «لندتک / بانک منتخب — نمونه ۲». نام ساختگی (مثل «ترنم») ممنوع است.
- یک دکمهٔ primary در هر ردیف (`.btn.pri`). بقیه `.btn.gh`. حداقل ارتفاع ۴۸ پیکسل (۴۴ برای `.btn.sm`).
- شناسهٔ مشتری: نشان خاکستری قابل‌کپی `.cid` بعد از نام، نه چسبیده به عنوان. پرونده: «پرونده #…» با `.mc-caseid`.
- طرح یکسان مجاز نیست. `.mc-warning` طلایی است (`#FEF8EA` / حاشیه `#F7D27F` / پد ۱۲ / شعاع ۱۲ / ۱۴ پیکسل) و علت را می‌گوید. دکمهٔ primary «انتخاب طرح دیگر» کانون را به کاشی‌های طرح برمی‌گرداند؛ «مشاهده‌ی پرونده» `.btn.gh` است. «ادامه» باید `.btn[aria-disabled=true]` باشد: `background: var(--nf-surface-2); color: var(--nf-ink-muted); cursor: not-allowed;` و حداقل ارتفاع ۴۸ پیکسل. متن نمونه: «این مشتری از قبل پرونده‌ی باز با همین طرح دارد (پرونده #…). تا لغو یا تکمیل آن، پرونده‌ی تازه با همین طرح ساخته نمی‌شود.»
- در انتخاب‌گر، گزینهٔ پیش‌فرض انتخاب‌شده «تماس/یادآور عمومی مشتری» است. «عمومی» فقط با انتخاب صریح.
- این کلاس‌ها را از `src/mc.css`، `src/shell.css`، `src/bl.css` و `tokens/tokens.css` برداشتیم. مقدارها را حدس نزنید؛ اگر چیزی نبود به همان منبع برگردید.
